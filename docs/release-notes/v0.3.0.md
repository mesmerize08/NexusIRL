This release fixes camera switching and the Portrait button, makes video and audio timing as even
as Moblin's, improves recordings, and adds encrypted settings exports. It is also the first
release that F-Droid's tools can build from source.

**Which file:** `NexusIRL-v0.3.0-arm64-v8a.apk` for practically every phone from the last several
years, or the universal APK for anything else. It installs over earlier versions and keeps your
settings.

## Fixed

- **Back and front camera:** switching failed with "Camera session configuration failed" or
  "Camera error 2" because the next camera opened before the previous one had closed. Cameras now
  take turns, and quick taps end on the camera you chose last. Old camera errors clear once the
  camera works again.
- **Portrait button:** with a landscape stream the picture was sideways when holding the phone
  upright. It now stays upright, as in Moblin, and the stream shows a landscape crop of it.
- Back from the LUTs or Widgets screen, opened with a quick button, returns to the main screen.
- Two crashes: turning the screen off while the preview was being set up, and quick scene switches
  while the camera was opening.

## Improved

- **Even timing:** every video frame and audio frame is sent exactly one frame time after the one
  before, like Moblin's frame timer, which players and streaming servers handle best.
- **Recordings** use B-frames for better quality at the same size, start exactly with the picture
  and keep their last frames.
- **Microphone:** mono by default, as in Moblin. Turn on **Prefer stereo** in the microphone
  picker for stereo from the built-in microphones.

## New

- **Encrypted settings exports:** exporting with stream keys can encrypt the file with a passphrase
  (AES-256-GCM). NexusIRL asks for the passphrase when importing it. The unencrypted export for
  iOS Moblin is still available.

## Tested

- Galaxy S26 Ultra: every main-screen control and screen (27 checks), 60 rapid back/front camera
  switches, the Portrait button held upright with both cameras, a 5-minute stream to a test server
  with every frame evenly spaced, and Moblin's own system tests for settings, scenes, RTMP
  streaming and six recording formats.
- F-Droid's scanner and build tools build and pass this version.
