This release fixes streaming on Android 10 to 12, makes the stream's audio bitrate setting work,
and adds SRTLA connection priorities from Moblin.

**Which file:** `NexusIRL-v0.5.1-arm64-v8a.apk` for practically every phone from the last several
years, or the universal APK for anything else. It installs over earlier versions and keeps your
settings.

## New

- **SRTLA connection priorities**, as in Moblin (Streams → edit → SRT → Connection priorities, or
  the new Connection priorities quick button): give mobile data, Wi-Fi, Ethernet and each Moblink
  relay a priority from 1 to 10, or turn a connection off. Changes apply while live, and
  priorities in imported Moblin settings are used.
- More of the app is translated, using Moblin's translations (OBS remote control, Kick alerts,
  Twitch banners, audio settings).

## Fixed

- **Android 10 to 12:** SRT and SRTLA streams whose URL has a stream ID stayed at "Connecting"
  forever, because the app used a Java method that only exists from Android 13. RTMP servers that
  ask for a user name and password, Twitch searches and chat messages, encrypted settings files
  and some timestamp comparisons had the same kind of problem. A new build check now compares the
  app's shared code with what Android 10 provides, so this cannot slip through again. If a stream
  ever fails to start like this, the app now says so instead of waiting.
- **Audio bitrate:** the stream's audio bitrate setting (also from imported Moblin settings) was
  ignored, and audio always went out at 128 kbps. Streams and recordings now use their own
  setting, within what the phone's encoder can do.
- **Camera back after another app:** after another app used the camera while live (for example
  the phone's Camera app), the picture stuttered for several seconds once the camera returned.
  It now stays at full frame rate.
- If a phone cannot encode Opus, the app says it is streaming AAC instead; if audio cannot start
  at all, it says the stream has no sound.

## Tested

- Huawei P30 Pro (Android 10, no Google services): live to a server over SRTLA with AAC audio,
  after the Android 10 fix (before it, the stream stayed at "Connecting").
- Galaxy S26 Ultra: live while walking (switching to the Camera app and back, recording, the
  front camera, filters); live at home with a recording, switching between the built-in
  microphone and Bluetooth earbuds; connection priorities, switching between Wi-Fi and mobile
  data and running on mobile data only.
- The unit and interoperability tests, now including a check of the shared code against
  Android 10's API.
