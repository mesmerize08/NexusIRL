A fix-up release: it closes a crash in the web remote control and makes remote control and
YouTube settings move between NexusIRL and iOS Moblin. Most of it was found by running Moblin's own
system tests against NexusIRL for the first time.

**Which file:** `NexusIRL-v0.2.1-arm64-v8a.apk` for practically every phone from the last several
years, or the universal APK for anything else. It installs over v0.1.x and v0.2.0 and keeps your
settings.

## Fixed

- **Crash (security):** the app closed when a browser dropped its connection to the web remote
  control in the middle of a page. Anyone on the same network could cause it, even without the
  access link. Only affects phones with the web remote control turned on (it is off by default).
- **iOS settings:** the remote control connection and YouTube video IDs were stored under different
  names from iOS Moblin, so they did not carry over in either direction. Your existing settings are
  converted automatically.
- **Remote control status:** assistants (Moblin on an iPhone, the web remote control) now show the
  actual bitrate with the total sent, and the uptime, as with an iPhone streamer.
- Remote control commands take effect before they are confirmed, as in Moblin.

## New

- **Web remote control Recordings page:** list, download, delete and preview the phone's
  recordings from a browser.
- **Stream logs for testing away from a computer:** the app keeps a per-second log of the last 10
  streams (frame rate, bitrate, connection quality per network). **Share diagnostics** includes
  it. No stream keys, picture or sound.

## Tested

- A 60-minute stream from a Galaxy S26 Ultra (1080p30 H.265 over SRTLA): every second at 30 fps on
  average, no reconnects, no gaps, no audio/video drift.
- Moblin's system tests: settings import, scene switching and RTMP streaming pass on the S26.
