This release adds Moblin's chat bot, multi streaming and Discord snapshots, brings images along
with imported settings, and fixes dropped frames at the start of 60 fps recordings. It is also the
first release submitted to F-Droid.

**Which file:** `NexusIRL-v0.4.0-arm64-v8a.apk` for practically every phone from the last several
years, or the universal APK for anything else. It installs over earlier versions and keeps your
settings.

## New

- **Chat bot** (Settings → Chat → Bot), as in Moblin: you and your moderators type `!moblin`
  commands in chat to switch scenes, mute and unmute, zoom, turn the torch and effects on and off,
  take snapshots, and start or stop the stream or change its Twitch title and category. Each
  command has Moblin's permissions (moderators, subscribers, everyone, cooldown) and aliases such
  as `!screen` work. Chat bot settings import from iOS Moblin. See the
  [chat bot guide](https://mesmerize08.github.io/NexusIRL/chat-bot.html).
- **Multi streaming:** an RTMP stream can also go to more RTMP servers at once, for example Twitch
  and YouTube, from the same encoder (Streams → edit → Multi streaming). Each destination
  reconnects on its own, and its stream key is protected like the stream's own.
- **Snapshots to Discord:** set a Discord webhook per stream (Streams → edit → Discord), with a
  separate one for chat bot snapshots and an "only when live" switch. The chat bot's snapshot can
  also come from another phone's web remote control.
- **Forwarded chat:** chat and Twitch alerts forwarded by a remote control assistant show in chat,
  the chat widget and alert pop-ups.
- **Bonding status:** while live over SRTLA, the main screen shows each network's share of the
  data, for example "60% Cellular, 40% WiFi".

## Fixed

- **60 fps recordings** could miss frames at the start: starting or stopping a recording or stream
  held up the video for up to a tenth of a second.
- **Imported settings** now bring their images (image widgets and LUT files), and exports include
  them. Image widgets apply their LUT effects.
- After importing settings without quick buttons, mute, torch and effects did nothing until the
  app was restarted.
- A scene whose camera is "None" shows black behind its widgets, as in Moblin.
- Two crashes: stopping a stream within a moment of starting it, and an emote without a name in
  chat.

## Changed

- Built with the latest Android build tools (Android Gradle Plugin 9.4, Kotlin 2.4, compile SDK
  37). The app still targets Android 16.

## Tested

- Galaxy S26 Ultra: every main-screen control and screen (27 checks), a camera stress test, and
  Moblin's own system tests for settings, scenes, RTMP and multi-RTMP streaming, chat and the chat
  bot, and six recording formats including 1080p60.
- The emulator UI tests, and F-Droid's scanner and build tools.
