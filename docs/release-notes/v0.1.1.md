A small update to the first test release, mainly so that testers can send useful bug reports.

**Which file:** `NexusIRL-v0.1.1-arm64-v8a.apk` for practically every phone from the last several
years, or the universal APK for anything else. It installs over v0.1.0 and keeps your settings.

## New

- **Share diagnostics** (bottom of the main screen): creates a text report for a bug report, with
  app and phone details, what the app is doing, your settings and the app's recent log. Stream
  keys, passwords and tokens are removed, and nothing is sent unless you share it yourself.
  Please attach it when you [report a problem](https://github.com/mesmerize08/NexusIRL/issues/new/choose).

## Behind the scenes

- Automated UI tests now run on an Android emulator for every change.
- Monthly dependency update checks and security alerts are enabled.

Everything in the [v0.1.0 notes](https://github.com/mesmerize08/NexusIRL/releases/tag/v0.1.0)
still applies, including what has and has not been tested yet.
