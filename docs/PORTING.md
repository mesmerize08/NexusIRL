# Porting tracker

This file maps upstream Moblin sources (`upstream/`, pinned at `97e26d2`) to their Kotlin ports.
When the submodule is bumped, check every row for upstream changes:

```sh
git -C upstream diff <old>..<new> -- <path>
```
